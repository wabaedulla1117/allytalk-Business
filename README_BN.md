# Tallytalk Business — মোবাইল দিয়ে APK তৈরি

## এই সংস্করণে
- কাস্টমার/সাপ্লায়ার/নিজের ব্যবসার হিসাব যোগ করা
- নাম, মোবাইল, বিবরণ ও টাকার পরিমাণ
- পাওনা, জমা, আয় ও খরচের এন্ট্রি
- ফোনে স্থানীয়ভাবে হিসাব সংরক্ষণ (SharedPreferences)

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি প্রথম পরীক্ষামূলক সংস্করণ। এখনো অনলাইন অ্যাকাউন্ট, Firebase cloud sync, একাধিক ব্যবহারকারীর আলাদা লগইন, QR পেমেন্ট বা বাস্তব টাকা পাঠানো যুক্ত নেই। এই সংস্করণে তথ্য এই ফোনেই থাকে; অ্যাপের ডেটা মুছে গেলে হিসাব হারাতে পারে। সংবেদনশীল ব্যবসায়িক হিসাব রাখার আগে ব্যাকআপ/ক্লাউড ব্যবস্থা যোগ করা প্রয়োজন।

## GitHub থেকে APK বানানো
1. GitHub repository-তে project files আপলোড করুন; ZIP ফাইলটি নিজে repository-তে শুধু ZIP হিসেবে রাখবেন না—ZIP extract করে ভেতরের ফাইল/ফোল্ডার আপলোড করুন।
2. `.github/workflows/build-apk.yml` ফাইলটি ঠিক এই path-এ থাকতে হবে।
3. Actions tab খুলুন। `Build Android APK` workflow চালু করুন বা main branch-এ push করুন।
4. সফল হলে workflow run-এর নিচে Artifacts থেকে `tallytalk-business-apk` ডাউনলোড করুন।
